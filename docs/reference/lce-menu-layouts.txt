LCE menu layouts - live runtime dump
====================================

Captured with:  Minecraft.Client.exe -flashui
(see Win64CommandLine::WantsFlashUI and UIScene::DumpLayout)

These are the REAL console layouts, read out of the running Flash UI. They are
the source of truth for reproducing each menu natively - tools/swf_layout.py
gives positions from the .swf, but width/height only exist at runtime because
the controls are AS3 library instances placed with no character id.

Coordinates are in the movie's own space (see the "movie" size on each scene),
which is what UIScene::getMovieWidth/getMovieHeight report. Scale to the render
target the way UIControl does. Note the 1080 assets are the 720 ones at 1.5x.
